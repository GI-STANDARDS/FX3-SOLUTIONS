2. THUMBNAIL ARCHIVE

thumbnails/thumbnails.zip contains 2,050 PNG images. Each image is a
picture of a Far Cry 3 prop, rendered at runtime by Far Cry 3's own object
renderer while the author was using a legally purchased copy of the game.
The source library includes a third-party object pack.

Rendering does not create a new, author-owned artwork. The underlying
props are Ubisoft's, so the archive is Ubisoft-derived material. The
author claims no copyright in the images, grants no license to them, and
could not.

The archive is provided for private study, personal backup, and
NonCommercial modding on top of your own copy of the game. It is not
licensed for redistribution, mirroring, bundling, or commercial use. If
Ubisoft or another rights holder asks for the material to be removed, it
will be removed.
